# 更新日志

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 的轻量变体，版本号规则 `yyyy.MM.dd.nn`（nn = 当日第几次发版）。
条目写法：`- [标签] 内容`，标签 ∈ `新增` / `修复` / `优化` / `移除`；
同标签条目相邻成组，组序固定 `新增 → 修复 → 优化 → 移除`，组与组之间用 `---` 单独一行的间隔线分隔（只有一组时不加）。
旧式 `### 新增` 分组写法仍兼容（条目继承分组标签）。
多语言：所有版本节（含 [未发布]）需同步翻译到同目录 `CHANGELOG.en.md` / `CHANGELOG.ja.md` / `CHANGELOG.ko.md`
（标签本地化：en 用等长简写 [Add]/[Fix]/[Chg]/[Del]，ja [追加]/[修正]/[改善]/[削除]，ko [추가]/[수정]/[개선]/[제거]；
locale 文件中 [未发布] 的节标题保持字面值不译——它是与中文版对齐的合并键，展示时会自动本地化；
版本号/日期/间隔线原样；缺译的版本节会自动回退中文，宁缺勿错）。
起草可用 `just changelog-draft app=online`，发版前人工润色为用户视角措辞。
