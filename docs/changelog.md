## [2026.08.13.01] - 2026-08-13

### 新增

- 实验性功能新增「玻璃拟态」：面板化作半透明磨砂玻璃，透出随主题色缓慢漂移的氛围光斑（品牌色联动，换主题色光斑跟着变）；暗色模式下效果最佳；默认关闭，选择长期保存
- 实验性功能新增「液态折射」：玻璃边缘像真实透镜一样弯曲、折射背景并带色散边（iOS 风格液态玻璃）；仅在开启玻璃拟态且使用 Chromium 内核浏览器时生效，其余浏览器自动停留磨砂玻璃档

### 优化

- 玻璃拟态细节修正：预览弹窗罩层与全局玻璃同材质（保留封面底图特色，暗色下不再是近实心黑罩）；弹窗不透明度提到透而不乱的平衡点，设置等弹窗不再透得发花；液态折射滤镜改为纯位移结构并前置磨砂模糊，去除大面板上的双重曝光"负片感"
- 玻璃拟态层次治理：磨砂模糊只保留在最外层面板——表格、歌词面板、播放器条等子表面统一透明化直接透出外层玻璃（此前多层半透明叠涂越叠越浑）；各面板头与面板融为一体；光明模式下玻璃边框由白色改为深色发丝线（白边框叠浅色背景等于隐形）；表格行底线、分页顶线、表头底线、滚动缘装饰线及弹窗标题/底栏分割线统一与外框同色（--glass-border）
- 表格结构改造：表头从滚动区中移出，固定在滚动区之外（头表分离 + 横向滚动同步 + 滚动条宽度补偿）——滚动内容到顶自然消失，彻底告别 sticky 表头的透字/遮盖问题，全模式生效；玻璃模式下表头改用浅提亮，不再"暗色纯黑、亮色纯白"
- 玻璃拟态下播放列表的正在播放/hover 行配色改浅：原"实色垫层+渐变描边"技法在半透明令牌下会整行灌满品牌色，玻璃模式改用浅色提亮+品牌色描边
- 封面粒子效果升级：粒子云会随音乐实时律动 —— 每槌鼓点/贝斯都让粒子盘整体向外冲击、起伏提亮，间歇时缓缓平静（基于 Web Audio 实时频谱的瞬态检测，仅开启粒子封面时生效；音频跨域受限时仅无律动，不影响播放）
- 设置中的开关统一为品牌渐变样式：抽出公共组件 AppSwitch，「界面效果」「实验性功能」「MP3 下载」等所有开关开启态都跟随主题渐变，后续新开关直接复用

## [2026.08.12.04] - 2026-08-12

### 新增

- 设置新增「实验性功能」页：首个实验项「封面粒子效果」（Beta）—— 开启后预览封面化作会呼吸的粒子云，有立体厚度感，鼠标划过会起伏、推开；默认关闭，选择会长期保存；不支持或封面跨域受限时自动回退普通封面
- 设置通用页新增「界面效果」区块：首个开关「封面旋转」（默认开启）—— 播放时封面黑胶旋转现在可以关掉了；粒子封面同样支持旋转（shader 内旋转，呈唱片圆盘）

### 修复

- MP3 下载写入的封面图在部分音乐源下因跨域限制静默丢失：封面改由后端代理代取，标签封面恢复完整（同一代理也为粒子封面提供同源图片）

### 优化

- 封面旋转的暂停行为：普通封面按原速顺滑转完剩余角度回到正位再停（告别倾斜定格的「矩形套矩形」），粒子封面则停驻在当时角度；继续播放均自然衔接
- 播放/暂停时封面圆⇄矩形过渡内外圈同步渐变，外圈不再瞬间变方
- 关闭预览弹窗时粒子封面保持最后一帧随弹窗收缩退场，不再闪白

## [2026.08.11.06] - 2026-08-11

### 新增

- 启动加载屏：打开应用时展示音符图标 + 斑马纹渐变进度条，实时提示当前加载内容（主题、语言、播放列表、播放进度等真实加载步骤），完成后光圈扩散揭示主界面（替代此前的静态过渡页）
- 播放统计：每首歌自动记录累计播放次数与播放时长，列表中歌曲名下方以耳机图标 + 次数展示（淡化主题色）；播放次数按"有效播放"口径统计——实际听满 30 秒或完整听完才计一次，反复重开、听几秒就切走不会虚增；统计与播放列表独立存储，歌曲删除后重新搜索添加或下载回来，播放次数依然保留

### 优化

- 设置弹窗关闭动画：遮罩层淡出节奏与窗口收缩同步，不再出现遮罩先消失、窗口后收缩的脱节感
- 设置 → 关于 中的版本号改用主题色；更新日志时间线中当前版本节点使用主题色高亮，历史版本保持灰色
- 播放次数支持千分位分隔（12,345）
- Windows 安装包体积优化：exe 从 13.9MB 压缩至约 4.2MB（UPX），下载更快；macOS 因系统签名限制不压缩

### 修复

- 播放次数耳机图标颜色不跟随主题：根因是模板遗留的旧主题逻辑在启动时把主色覆写为灰紫色（inline 优先级最高），已彻底移除该遗留调用——顺带根治了同类"默认紫色"隐患的复发可能
