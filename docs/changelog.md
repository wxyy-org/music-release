# 更新日志

格式遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号规则 `yyyy.MM.dd.nn`（nn = 当日第几次发版）。

## [2026.08.11.06] - 2026-08-11

### 新增

- 启动加载屏：打开应用时展示音符图标 + 斑马纹渐变进度条，实时提示当前加载内容（主题、语言、播放列表、播放进度等真实加载步骤），完成后光圈扩散揭示主界面（替代此前的静态过渡页）
- 播放统计：每首歌自动记录累计播放次数与播放时长，列表中歌曲名下方以耳机图标 + 次数展示（淡化主题色）；播放次数按"有效播放"口径统计——实际听满 30 秒或完整听完才计一次，反复重开、听几秒就切走不会虚增；统计与播放列表独立存储，歌曲删除后重新搜索添加或下载回来，播放次数依然保留

### 优化

- 设置弹窗关闭动画：遮罩层淡出节奏与窗口收缩同步，不再出现遮罩先消失、窗口后收缩的脱节感
- 设置 → 关于 中的版本号改用主题色；更新日志时间线中当前版本节点使用主题色高亮，历史版本保持灰色
- 播放次数支持千分位分隔（12,345）
- Windows 安装包体积优化：exe 从 13.9MB 压缩至约 4.2MB（UPX），下载更快；macOS 因系统签名限制不压缩

### 修复

- 播放次数耳机图标颜色不跟随主题：根因是模板遗留的旧主题逻辑在启动时把主色覆写为灰紫色（inline 优先级最高），已彻底移除该遗留调用——顺带根治了同类"默认紫色"隐患的复发可能

## [2026.08.11.02] - 2026-08-11

### 新增

- 双击启动自动接管端口：新版本启动时若端口被旧实例占用，自动关闭旧进程并以新版本启动（含守护进程场景），双击即用不再被旧版本"劫持"

### 修复

- 设置面板多处组件默认显示为模板紫色、未跟随主题色：功能开关、语言选中态、主题色板选中外环均改为品牌渐变
- 语言选中按钮底色透明导致整颗按钮被渐变填满；主题色板 hover 放大时选中环遮挡相邻色板

## [2026.08.11.01] - 2026-08-11

### 新增

- MP3 下载：搜索结果行新增下载按钮，音频在浏览器内转码为 MP3 并自动写入歌曲信息（标题/艺术家/专辑/封面/歌词），下载进度弹窗实时可见。该功能默认关闭，可在 设置 → 通用 → 功能 中开启
- 应用内检查更新与一键升级：设置 → 关于 → 版本更新，发现新版本时版本号旁显示 new 角标，点击「立即更新」自动下载、替换并重启完成升级（单文件分发形态）
- 设置弹窗切换标签时高度平滑过渡，不再突变

### 优化

- 搜索结果表格：长标题悬停显示完整歌名（仅超长省略时提示），操作列加宽避免按钮拥挤，消除窄屏横向滚动条

## [2026.08.10.03] - 2026-08-10

### 新增

- 单文件分发：双击即用，无需服务器与任何环境依赖，支持 macOS / Windows
- Windows 版静默后台运行：双击不弹黑窗，日志落在 exe 同目录 `music-online.log`
- 开机自启 + 崩溃守护：`-install` 一键注册，异常退出自动拉起
- 设置中心：齿轮入口，含主题设置与关于页
- 主题自定义：内置纯色 / 渐变色板，支持自定义取色，偏好持久保存（换设备更新不丢）
- 暗黑模式开关，跟随记忆上次选择
- 设置内可查看当前版本号与更新日志（就是本页）

### 修复

- 弱网环境下搜索/查询频繁超时：前端等待时间延长至 30s，覆盖上游人机验证往返
- 暗黑模式切换动画从屏幕中央扩散的问题，现在从开关位置扩散
- 刷新页面后暗黑开关状态与页面实际明暗不一致
