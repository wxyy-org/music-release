# 常见问题（FAQ）

## 双击没反应 / 浏览器没有打开

正常情况下不会发生：端口被旧版本占用时新程序会自动接管。如果确实没反应：

1. 确认端口 `31004` 是否被**其他程序**占用：
   - macOS：`lsof -nP -iTCP:31004`
   - Windows：`netstat -ano | findstr 31004`
2. 被其他程序占用时，结束该程序，或让 music-online 换端口启动（见 [快速上手 → 更换端口](/guide/quickstart#_4-更换端口-可选)）
3. 查看日志定位：
   - Windows：exe 同目录的 `music-online.log`
   - macOS：`$TMPDIR/music-online.log`

## 查询超时 / 搜索一直转圈

- 前端等待上游音乐源的最长时间为 30 秒，超时说明**音乐源在你当前网络下不可达**
- 偶发：稍后重试即可
- 频繁：切换网络环境（如关闭/更换代理）后再试

## macOS 提示"无法打开"

因为应用未经过 Apple 公证，首次打开会被 Gatekeeper 拦截。两种解法任选：

1. **右键**（或 Control+点击）程序 → 「打开」→ 在弹窗中再点「打开」（只需一次）
2. 终端执行：
   ```bash
   xattr -d com.apple.quarantine /路径/music-online-darwin-arm64
   ```

## Windows 如何彻底卸载

1. 如果设置过开机自启，先执行 `.\music-online-windows-amd64.exe -uninstall`
2. 在任务管理器结束 `music-online-windows-amd64.exe` 进程
3. 删除 exe 文件与同目录的 `music-online.log`

::: tip 你的个人数据不在安装目录里
播放列表、主题设置、播放统计都保存在**浏览器的站点数据**（IndexedDB）中。
删除 exe 不会影响它们；下次重新下载运行，数据原样恢复。
只有手动清除浏览器站点数据才会真正清空——所以「清除残留」不需要动浏览器缓存。
:::

## 关闭了命令行窗口后功能失效

这是旧版本的现象：**当前版本 Windows 双击运行不弹控制台窗口**，静默后台运行，不存在"关窗杀进程"的问题。
如果你还在用很旧的版本，升级到最新版即可（见 [应用内更新](/guide/self-update)）。

## 数据都保存在哪里

全部在浏览器本地（IndexedDB），卸载/重装程序不会丢失：

| 数据 | 说明 |
| --- | --- |
| 播放列表 | 添加的歌曲与顺序 |
| 主题色 / 语言 / 暗色模式 | 个性化设置 |
| MP3 下载开关 | 功能开关状态 |
| 播放统计 | 每首歌的播放次数与时长 |

清除浏览器站点数据会同时清空以上全部内容。
