# 功能指南

## 搜索与播放

- 顶部搜索框输入歌曲名 / 歌手名，回车搜索
- 点击结果行的歌曲即可播放；播放中的歌曲在底部播放器控制
- 歌曲标题过长时自动省略，鼠标悬停可查看完整标题

## 歌单

- 搜索结果可「添加」到播放列表，播放列表持久保存在本地（IndexedDB），刷新不丢失
- 列表循环播放：播完最后一首自动回到第一首

## 歌词

- 点击歌曲可打开预览窗口：封面、播放控制、滚动歌词
- 当前演唱行高亮（跟随主题色），点击歌词可跳转进度

## 主题色

打开右上角 **设置 → 通用 → 主题**：

- **纯色**：6 个预设纯色 + 自定义取色器
- **渐变**：6 个预设渐变 + 自定义起止两个颜色
- 设置保存在本地（IndexedDB），**应用升级后不会丢失**

主题色会全局生效：按钮、开关、歌词高亮、播放进度条、加载进度条等。

## 暗色模式

界面上的暗色开关（太阳/月亮图标）可在光明 / 暗黑模式间切换，带平滑过渡动画，
选择结果同样持久保存。

## 多语言

设置 → 通用 → 语言，支持 **中文 / English / 日本語 / 한국어**，切换即时生效。

## 播放统计

歌曲行会显示耳机图标 + 播放次数（千分位格式化）。计数规则：

- **开始播放不计数**，累计实际播放满 30 秒或自然播完才计 1 次——反复点播放不会虚增
- 统计与播放列表解耦：删掉歌曲再添加回来，播放次数依然保留
- 统计保存在本地，清除浏览器站点数据会一并清除

## 启动加载页

每次启动会显示加载页，进度条对应真实加载步骤（主题 → 语言 → 播放列表 → 会话），
加载完成以光圈扩散动画进入主页面。
