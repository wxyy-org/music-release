# MP3 下载

music-online 支持把搜索到的歌曲下载为 **MP3 文件**（含歌曲名、歌手、封面等元数据标签）。

## 开启下载功能

下载功能**默认关闭**。开启方式：

1. 打开 **设置 → 通用**
2. 在「功能」区块打开 **MP3 下载** 开关
3. 搜索结果的操作列会出现下载按钮（⬇）

开关状态保存在本地，升级应用不会重置。

## 下载流程

点击下载按钮后：

1. 获取音频源文件（m4a）
2. **在浏览器内转码为 MP3**——转码在你本机完成，不经过任何第三方服务器
3. 自动写入 ID3 标签（歌曲名、歌手、专辑封面）
4. 弹出下载进度对话框，完成后保存到浏览器下载目录

::: tip 为什么下载需要一点时间？
转码完全在浏览器内进行，速度取决于你的设备性能。一首 4 分钟的歌曲通常需要几秒到十几秒。
:::

## 常见问题

- **没有看到下载按钮**：确认设置中 MP3 下载开关已打开
- **下载失败**：多为上游音乐源网络问题，稍后重试；频繁失败见 [常见问题 → 查询超时](/guide/faq#查询超时)
