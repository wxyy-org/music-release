# 应用内更新

music-online 自带更新机制，**无需手动下载替换**。

## 检查更新

打开 **设置 → 关于**，「版本更新」区块会：

- 打开关于页时**自动静默检查一次**
- 也可以随时点「检查更新」手动检查

## 有新版本时

- 版本号右上角会出现 **new 角标**
- 点击「立即更新」：
  1. 进度条显示下载进度（跟随主题色）
  2. 下载完成后自动替换程序并重启
  3. 页面自动刷新，即已完成升级

整个过程通常十几秒，播放列表、主题设置、播放统计等本地数据**全部保留**。

## 更新失败怎么办

- 更新服务托管在 GitHub，国内网络偶尔不稳定——**切换到服务器镜像源**（见下），或到
  [Releases 页面](https://github.com/wxyy-org/music-release/releases/latest) 手动下载最新版覆盖旧文件即可
- 手动覆盖不会丢失任何数据（数据都在浏览器本地存储中）

## 更新源（GitHub / 服务器镜像）

「版本更新」区块下方有**更新源**选择：

- **GitHub Release**（默认）：从 GitHub 下载更新
- **服务器镜像**：从自建服务器下载——**连不上 GitHub 时切换到这个**

每个源旁边有一个状态图标：

- 绿色 ✓ = 当前网络可达；红色 ✗ = 不可达
- **每次打开关于页都会自动重新检测**；点击图标可手动重新检测
- 看不懂图标含义？点旁边的问号有说明

你的选择会自动保存，下次打开应用依然生效。

## 查看更新内容

- 应用内：**设置 → 更新日志**，按版本时间线展示每个版本的新特性与修复
- 网页版：[更新日志](/changelog)
